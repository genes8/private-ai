# Mission: Strategic Programming

## Why
The user wants to become the kind of programmer whose value is not limited to writing code that AI can increasingly generate. The goal is to develop senior-level strategic engineering judgment: planning, tradeoff analysis, QA design, codebase stewardship, and technical decision-making.

## Success looks like
- Turn ambiguous product or engineering requests into scoped, testable implementation plans.
- Identify risks, coupling, missing evidence, and verification gaps before code is written.
- Design changes so they are reviewable, reversible, observable, and maintainable.
- Use AI as a tactical amplifier while keeping human ownership of direction, judgment, and quality.

## Constraints
- Lessons should be short, practical, and tied to real software work.
- The teaching should emphasize source-backed engineering practices, not generic career advice.
- Exercises should create artifacts the user can reuse inside this repository.

## Out of scope
- Pure coding syntax drills.
- Generic productivity advice detached from codebase, product, or operational consequences.
- Management-track leadership unless it directly improves technical strategy.
