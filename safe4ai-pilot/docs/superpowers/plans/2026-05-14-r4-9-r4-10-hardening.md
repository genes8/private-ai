# R4-9 and R4-10 Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `cache_total_hits` reflect cache hits that occurred within the requested period, and harden `reindex_document` so Qdrant reset failures do not leave the database in a partially-reset reindex state.

**Architecture:** Add a small append-only cache-hit event table so period-scoped cache-hit metrics can be computed accurately without guessing from lifetime counters. Reorder the reindex workflow so external reset steps succeed before destructive DB changes are committed, which removes the current partial-failure inconsistency without requiring distributed transactions.

**Tech Stack:** FastAPI, SQLAlchemy ORM/Core, PostgreSQL, Qdrant, pytest

### Task 4: Remove partial DB reset from `reindex_document` when Qdrant reset fails

**Files:**

- [ ] **Step 1: Write the failing test**

Add a regression test for `reindex_document` where `_delete_qdrant_points()` raises. Assert:
- response is `502`
- no DB chunk delete/version bump/job creation commit happens before Qdrant reset succeeds
- document is not left in a partially-reset queued state

- [ ] **Step 2: Run test to verify it fails**

Run: `./.venv/bin/pytest tests/test_admin.py -q`
Expected: FAIL because the current flow commits DB chunk deletion and version bump before Qdrant delete.

- [ ] **Step 3: Write minimal implementation**

Refactor `reindex_document()` order:
1. validate doc/raw file
2. block active ingestion job
3. attempt external reset steps first:
   - `_delete_qdrant_points(doc_id)`
   - `retriever.remove_from_bm25(doc_id)` if available
4. only after external reset succeeds, open DB transaction and:
   - invalidate semantic cache
   - delete `DocumentChunk` rows
   - bump `version`
   - set `active_version`
   - set `ingestion_status=queued`
   - create `IngestionJob`
5. schedule ingestion task

If external reset fails, return `502` without mutating DB state.

Run: `./.venv/bin/pytest tests/test_admin.py -q`
